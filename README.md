# Open WKF Scoreboard 🥋

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![Engine: Godot 4](https://img.shields.io/badge/Godot-v4.3%2B%20.NET-blue.svg)](https://godotengine.org/)
[![Language: C#](https://img.shields.io/badge/Language-C%23-purple.svg)](https://docs.microsoft.com/en-us/dotnet/csharp/)

An open-source, lightweight, cross-platform digital scoreboard designed for World Karate Federation (WKF) Kumite and Kata competitions. Built with **Godot Engine 4 (.NET / C#)** for native, high-performance rendering on Windows, Linux, and macOS.

---

## 🚀 Download & Installation

You can download pre-compiled standalone executables for your operating system from the GitHub Releases section:

📦 **[Latest Releases & Binaries](https://github.com/Aanxhel/open-wkf-scoreboard/releases)**

* **Windows 10/11:** Download the `.zip` archive, extract, and run `open-wkf-scoreboard.exe`.
* **Linux (LMDE, Ubuntu, Debian, Arch):** Download the `.tar.gz` or binary, make it executable (`chmod +x`), and run.
* **macOS:** Download the `.app` bundle.

---

## ✨ Key Features

* **WKF Ruleset Compliant:** Complete support for Kumite points (*Yuko*, *Waza-ari*, *Ippon*), *Senshu* advantage, and 8-point gap rule (*Kachi*).
* **Penalty Management:** Full tracking for Category 1 (C1) and Category 2 (C2) warnings (*Chui 1-3*, *Hansoku Chui*, *Hansoku*).
* **Precise Match Timer:** High-precision countdown with visual indicators for final 10-second tenths and audio alerts.
* **Keyboard Control:** Optimized hotkey mapping for scorekeeper efficiency without relying on mouse movement.
* **Dual-Monitor / Projector Support:** Easily project the scoreboard layout to external screens while keeping control locally.
